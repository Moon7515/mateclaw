## 🧭 What is mateclaw?

MateClaw is a desktop app that helps you chat with an AI assistant, keep notes, and organize tasks in one place. It is built for people who want a second brain that can remember past work, help with plans, and support different chat channels.

You can use it to:
- Save useful notes and ideas
- Chat with an assistant that keeps context
- Link memory to past tasks and decisions
- Use agents that can break down work into steps
- Connect with tools through MCP
- Work across chat platforms like Discord, Telegram, Feishu, and DingTalk
